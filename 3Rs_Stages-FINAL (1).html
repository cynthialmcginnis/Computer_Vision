Stage 1: Raw Pixels (Numbers Only)

A photograph is 36.6 million RGB numbers in a grid. Each number (0-255) represents brightness. The computer sees only data—no meaning yet. This is the starting point: pure information with no understanding.

The 3 Rs Framework:

Recognition — "What is it?" Machine identifies objects by edges and shapes (Stage 2)

Reconstruction — "Where in 3D space?" Machine maps spatial location and depth (Stage 3)

Reorganization — "How do parts fit together?" Machine integrates all visual information into complete understanding (Stage 4)
